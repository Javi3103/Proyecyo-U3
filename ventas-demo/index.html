Microservicio Ventas (demo)

Simula un microservicio hijo real: no tiene base de usuarios propia, valida cada token contra el Master Gateway.

Este micro-frontend llama a POST /api/internals/validate-token del Master Gateway (Zero Trust — sección 6.1 del PDF) en vez de validar sesiones propias. La respuesta trae userId, roleId, role y permissions, que este microservicio usaría para decidir su propia lógica de autorización interna.
